# 部署到云服务器

整体流程：买一台海外云服务器，在网页里打开服务器终端，粘贴一行命令，回答 3 个问题，大约 10 分钟完成。

## 1. 买服务器

**为什么必须是海外地域**：OpenAI 和 Anthropic 的 API 不对中国内地和香港开放，服务器放在内地或香港会调不通模型。海外服务器另一个好处是**不需要 ICP 备案**，买完当天就能用。

**推荐**：阿里云国内站（aliyun.com，可以用支付宝）→ 产品「轻量应用服务器」。腾讯云的「轻量应用服务器」也可以，步骤几乎一样。

| 选项 | 选什么 |
|---|---|
| 地域 | **新加坡**或**日本（东京）**。不要选中国内地和中国香港 |
| 镜像 | **系统镜像 → Ubuntu 24.04**（22.04 也可以）。不要选应用镜像 |
| 套餐 | **2 核 4GB 内存**，系统盘 40GB 以上 |
| 时长 | 先买 **1 个月**试用 |

价格：以下单页显示为准。第三方整理的 2026 年 7 月价格中，阿里云香港 2 核 4GB 约 78 元/月，新加坡和东京通常在这个价位附近。

买完后在控制台做两件事：
1. **防火墙**：添加规则，放行 **80** 和 **443** 端口（TCP）。
2. **设置密码**：给 root 设置登录密码，或者直接用控制台的「远程连接」免密登录。

## 2. 一键部署

在服务器控制台点「远程连接」，会打开一个浏览器里的终端。粘贴下面这行命令，回车：

```bash
curl -fsSL https://raw.githubusercontent.com/rundong013-oss/ai-edu/main/deploy/install.sh | sudo bash
```

它会依次问你：
1. **OpenAI API key**：生图用。留空就先用模拟图。
2. **Anthropic API key**：Vibe Coding 和生文字用。留空就先用模拟。
3. **域名**：没有就直接回车，用服务器 IP 访问。
4. **是否创建演示账号**：直接回车（默认创建）。

接下来脚本会自动完成：安装 Docker、下载代码、生成随机密码、构建并启动。第一次大约 3–6 分钟。结束时会显示：
- 访问地址，例如 `http://1.2.3.4`
- 管理员和演示账号的密码。这些密码只在这里显示一次，同时保存在服务器的 `/opt/ai-edu/credentials.txt`

## 3. 日常操作

| 要做的事 | 命令（在服务器终端里执行） |
|---|---|
| 更新到 GitHub 上的最新代码 | `sudo bash /opt/ai-edu/deploy/update.sh` |
| 查看账号密码 | `sudo cat /opt/ai-edu/credentials.txt` |
| 查看运行日志 | `cd /opt/ai-edu && sudo docker compose logs app --tail 100` |
| 修改 key 或模型 | 编辑 `/opt/ai-edu/.env.production`，然后执行 `cd /opt/ai-edu && sudo docker compose up -d` |
| 重启 | `cd /opt/ai-edu && sudo docker compose restart` |

数据（数据库、图片、学生项目）都在 `/opt/ai-edu/data`，更新代码不会影响它们。建议定期用控制台的「快照」功能备份整台服务器。

## 4. 绑定域名（可选）

1. 在域名服务商那里添加一条 **A 记录**，指向服务器 IP。海外服务器不需要备案。
2. 在服务器上执行：
   ```bash
   cd /opt/ai-edu && echo "SITE_ADDRESS=你的域名" | sudo tee .env && sudo docker compose up -d
   ```
3. 一两分钟后，用 `https://你的域名` 访问。证书会自动申请和续期。

## 5. 常见问题

- **打不开网页**：检查防火墙有没有放行 80 端口；再看日志里有没有报错。
- **能打开，但生图或编程失败**：多半是 key 填错、余额不足，或者模型名不对。看日志里的 `[generation] failed` 或 `[coding] run failed`。
- **国内访问慢**：新加坡和东京可以各开一台测速对比，留下快的那台。
- **控制成本**：在 OpenAI 和 Claude Console 后台给 key 设置每月消费上限。平台的「算力用量」页能看到每个学生、每节课花了多少。

## 安全说明

- 服务器上不使用默认密码 `123456`。管理员和演示账号都是部署时随机生成的；登录页不显示演示账号的一键登录。
- 连续输错密码 10 次会锁定 15 分钟。
- 学生生成的图片和网页预览，是通过别人猜不到的链接访问的，没有做登录校验。不要在作品里放敏感信息。
- 正式给国内学生上课前，还要解决网站备案和生成式 AI 服务的合规问题（见 `docs/PRD.md`）。
