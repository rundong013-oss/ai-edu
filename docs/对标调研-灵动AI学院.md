# 对标调研：灵动AI学院（aicyld.com）

> 2026-10-26 · 来源：公开页面（首页、灵动课程、课堂作品、机构手册、常见问题、客户端下载、作品详情）、公开接口（作品广场、课包列表）、网站前端代码里的路由和界面文案。未登录，学生端、教师端、机构后台的内部页面没有实际操作过，相关结论来自前端文案，标注为「推断」。

## 一句话结论
灵动的产品骨架和我们规划的基本一致：机构 / 老师 / 学生三端、按课节预设框体的画布、Vibe Coding、课包授权。差别在于：
- **它的 Vibe Coding 是桌面客户端**（Windows / Mac 安装包，约 150MB），我们是网页端，不用安装；
- **它的额度管的是生意**：平台给机构「人次库存」，机构按学生核销；我们管的是**课堂里的单次生成**。
- **作品广场 216 件作品里，205 件是导入的展示样例**，真实课堂作品只有 11 件，都来自测试机构。这和通话里「还没有机构正式开课」的说法一致。

## 2. 画布机制（来自作品快照数据 + 前端文案）

**框体类型**：生文字、生图、生视频、生音乐，共 4 种。
- 生文字：模型 `deepseek-flash`，对外显示为「灵动文本2.0」。S1-2 里先用文字框写对联，再把对联喂给图片框生成配图。
- 生图：模型 `zhenzhen-image-g-v2.5-lowprice`，对外显示为「灵动图像2.5」，推测是 GPT Image 2.5 的低价中转。参数包括画幅（9:16 / 16:9 / 1:1 / 3:4 / 4:3）、分辨率（1k / 2k / 4k）、输入方式（文生图 / 参考图）。
- 生视频：支持首帧和尾帧；支持音频驱动对口型（「口型跟随 <Audio 1>」）。
- 生音乐：分「歌词生音乐」和「描述生音乐（平台代写词）」两种。

**配置方式**
- 「本框体的生成配置来自课时设置」：模型和参数由课节预设。每个框体里有一个 `studentParams` 字段，表示学生被允许改的参数。
- 有「框体素材」「框体预置」：课节内置素材，学生可以插入框体。
- 模型统一改名成「灵动××」，不暴露供应商。

**课堂规则**：下课后画布不能再修改；作品提交后还能继续做，做出新产出可以再提交。

**备课画布**：「备课模式 · 不生成」，草稿只保存在本机。

**作品快照**：提交时把整张画布（节点、连线、视口）存下来。作品页有「作品内容 / 创作画布」两个标签，可以回看学生的创作过程。

## 3. 额度与商业机制（来自后台文案，属推断）
- 课包标价 **¥8000 / 门**（S1–S3）。通话里说前 3 年授权费为 0，说明这是标价，不是实际成交价。
- 平台 → 机构：给机构开通课包和「人次库存」（总人次、期初人次、增购）。「算力额度按课包计」。
- 机构 → 学生：每给一个学生授权一个课包，用掉 1 人次。体验课包可以重复授权，规则是「每场课堂正常结束且有有效产出才核销 1 次」。
- 算力不足时：「平台不会因为算力用量去拦学生」，而是提示老师补足授权次数。**也就是说，它不在课堂里硬拦学生。**
- 每个老师同时只能有一个「待上课 / 上课中」的课堂，要先结束或解散当前课堂，才能创建下一个。
- 后台有：课包库存、学生授权中心、算力用量（消耗、调用次数）、作品精选（发布到作品广场）、作品报告、分享链接。

## 4. Vibe Coding 作品的额外能力
- 学生做的网页可以通过平台接口 `/api/llm` 调用大模型（「作品调用大模型」）。分享出去后，访客要在「接口设置」里填自己的 key，key 只存在浏览器里。
- 老师端和平台端的预览**故意断网**，属于安全设置。
- 作品类型很多：网页、小游戏、智能体、工作流、PPT、绘本、播客、音乐、品牌设计；还能在线查看 docx / pptx / xlsx。

## 5. 课程内容
共 7 个课包（前端文案写的是「11 门 / 87 节」，可能包含尚未公开的课包）：

**S1 · AI 魔法启蒙营**（8–16 岁，难度 2/5，16 × 90 分钟）
1-1 AI 初识：召唤哪吒 · 1-2 提示词密码：吟诗作对 · 1-3 AI 造梦工坊：故事美文 · 1-4 魔法画室：漂浮都市与画风 · 1-5 神笔焕新：涂鸦变插画 · 1-6 星际绘本师：角色一致性 · 1-7 纸片人剧场：图生视频 · 1-8 国宝焕活：清明上河图动起来 · 1-9 怪兽动画师：多场景动画 · 1-10 智能体探秘：猜谜大师 · 1-11 古诗丹青手 · 1-12 知识库挂载：班级小助手 · 1-13 AI 编程入门：对话搭建网站 · 1-14 逻辑指令官：互动小游戏 · 1-15 全能实战营：电子宠物 App · 1-16 AI 思辨课：作品归属与科技影响

**S2 · AI 人文数字探索营**（9–16 岁，难度 3/5）：旅行规划手绘、计算机视觉、预测与数学、信息茧房、草图变名画、古画取色、AI 作曲、山海经神兽动画、老照片修复、文物纹样补全、3D 古画、甲骨文演变、英语对话网站、记账工具、文物扫码导览、数字博物馆。

**S3 · AI 全栈应用实战营**（10–16 岁，难度 4/5）：PPT 自动化、海报排版、有声绘本、性格测试表单、情绪识别陪伴、单词翻卡、扭蛋机、挂号向导、失物匹配、智能客服、适老化语音、网页抓取摘要、RAG 知识库、数据库、自定义 AI 伙伴、外部插件 / API。

**其它**：实体商家 AI 增长班（2 × 300 分钟）、成人 AIGC 短剧实战营（11 × 300 分钟）、两个体验课（就是概念视频里的「星光战甲兽」）。

**规律**：S1 前 12 节以画布为主（文字、图片、视频、智能体），后 3 节是 Vibe Coding；越往后的课包，Vibe Coding 和「做应用」的比重越高。

## 6. 作品广场的实际情况
- 共 216 件：画布 192、Vibe Coding 24。
- **205 件是「imported」展示样例**，来自约 10 个机构名（麦田少儿科创、云雀AI创意学院等）。真实提交只有 6 件画布作品（都来自「灵动未来科技」）和 5 件 Vibe Coding（来自测试机构）。
- 不少作品的图片和封面打不开（「图片已失效」），推测素材链接会过期。

## 7. 营销定位（官网和手册）
- 卖点：自研画布、国际顶级模型、「Agent 底座」Vibe Coding、48 节旗舰课、SaaS 管理系统；「老师只负责教」。
- 和其它 AI 课的对比话术：不用在多个网站间切换、不用自备 API key、课件内置、作品能沉淀、新老师可以复制整套流程。
- 机构手册大量引用各地中小学 AI 教育政策（北京每学年不少于 8 课时等），把跨学科和综合能力培养作为卖点。
- 资质齐全：ICP 备案、增值电信经营许可证（B2）、广播电视节目制作经营许可证。

## 对我们的启示

**可以直接借鉴**
1. **增加「生文字」框体**：文字框的输出可以接给图片框。这是 S1-2「提示词结构」类课程的基础，成本也最低。（已实现）
2. **框体参数由课节预设，学生只能改被允许的部分**：和我们的「填空模板」思路一致。可以把画幅、分辨率、输入方式也做成「课节决定，学生可选范围由课节限定」。
3. **作品页回看创作过程**：分享页展示提示词和画布过程，家长能看到孩子学到了什么，而不只是一张图。（已实现）
4. **作品广场 + 机构精选**：后续做。

**我们的差异化**
1. **Vibe Coding 不用装客户端**：浏览器直接用，实测首次预览 6–10 秒、完成 20–30 秒；灵动在通话中承认要 5–10 分钟。
2. **画布素材自动流到编程课**：第 3 节自动带入学生第 1 节的作品。
3. **老师端实时进度面板**：每个学生的状态每 3 秒刷新，作品可以一键投屏。

**需要决定的**
- 额度是否也要在课堂里硬拦？灵动在课堂里不拦学生，只在后台管人次。我们现在是在课堂里按框体硬拦，这个机制更细，对教学节奏的影响需要实测。
- 学生做的网页能否调用大模型（S3 智能体、RAG 类课程需要）：后续再定。
