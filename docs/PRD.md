# AI 教学一体化平台 — PRD v0

> 2026-10-26 · 对齐稿 + 进展。参考对象：灵动AI（概念视频 + 2026-10-25 通话 + demo 截图 + `claude/对标调研-灵动AI学院.md`）。

## 0. 为什么要做封装（设计原则）
我们做封装，只是把分散在各个平台的工具（生图、生视频、Claude Code）**放进同一个页面**，并且按课节把流程和额度管起来。
**封装不能让体验变差。** 判断标准是：学生在我们的页面里用 Vibe Coding，感受应该和直接用 Claude Code / Claude 网页版一致，包括流式对话、可见的执行进度、实时预览。

- **还原体验**：流式输出、工具步骤卡片、随生成刷新的预览框、可中断（stop）。
- **收窄能力**：不开放终端、任意 bash、联网搜索和权限弹窗；技术栈固定；按课节限额。
- **速度是硬指标**：每次生成都记录延迟指标，和用量写在同一份记录里。

## 1. 目标
做一个**标准化的 AI 教学一体化平台**。现阶段只验证机制，不考虑落地到机构，也不做招生物料。

**本期验收标准**：三端都能登录。老师开课 → 学生进课堂 → 在画布里生图（受额度限制）→ 用 Vibe Coding 把素材做成网页 → 提交 → 老师看到作品 → 作品分享页能在手机上打开。（已达成）

## 2. 角色
| 端 | 定位 | 本期功能 | 占位 |
|---|---|---|---|
| 机构 | 后台运营（admin） | 建老师/学生账号；给学生授权课包；配置课节额度；维护提示词（平台规则 + 积木库）；查看用量 | 计费、多租户 |
| 教师 | 用户 | 课程列表；创建课堂（课堂名 → 课包 → 课节 → 拉学生）；开课 / 下课；实时看进度和提交；投屏；进入画布演示（不能生成） | PPT、教案只放占位页 |
| 学生 | 用户 | 没开课时显示「等待开课」；进入课堂；画布；Vibe Coding；提交；我的作品；分享页 | — |

## 3. 核心机制

### 3.1 画布（AIGC Canvas）
- **一张画布对应一节课**，有明确的创作目的，不是自由画板。
- 左侧是任务列表，按步骤引导（任务一 → 任务二 → … → 自由创作）。
- 每个任务预设**框体（frame）**，类型包括 image / video / text。每个框体带提示词模板：模板里有可替换字段（slot），学生可以只改字段，也可以整段重写。
- 框体之间可以连线：上游的输出作为下游的参考输入（图生图、图生视频、看图写作；上游文字也能作为下游提示词的素材）。
- 生成是异步的：框体内显示进度，多个框体可以并行生成，生成期间不锁定画布。
- 老师端的画布只能演示，不能生成。

### 3.2 提示词分层
- **平台层（隐藏）**：生图、生视频、生文字、Vibe Coding 各一段儿童内容规范，自动追加，学生看不到也改不掉；屏蔽词命中直接拦下，不扣次数。
- **课节层**：框体的填空模板。
- **学生层**：提示词积木（风格、光影、镜头、场景、细节、动作、特效、体裁、语气），框体只开放相关类别，同一类别只能选一块。
- **素材层**：上游框体的图片和文字。

### 3.3 Vibe Coding（目标：最大程度还原 Claude Code 的体验）
**界面**
- 左侧对话面板：流式文字；工具调用显示成步骤卡片（如「写入 index.html」「修改 style.css」）；任务清单（todo）；停止按钮；一键插入画布素材。
- 右侧预览面板：写 HTML 时内容边写边进预览；文件写完自动刷新；可以切换手机 / 电脑视图；可以在新窗口打开；可以查看源码（只读）。

**速度方案**
1. 全程流式（SSE）。
2. 写文件的流式内容直接推进预览。
3. 课节脚手架 + 课节专用 CLAUDE.md。
4. 素材清单直接放进系统提示词，文字素材附内容，不让模型逐个读取。
5. 只开放 Read / Write / Edit / TodoWrite；只能读写学生自己的项目目录。
6. 会话续接，后续修改只做局部编辑。
7. 老师开课时预热：建好工作区和项目目录。

**目标指标**：首次可见预览 < 30s；首版完成 < 2 min。（实测已达成，见第 8 节）

### 3.4 算力 / 额度
- 额度**以课节为单位**发放。每个框体有 N 次生成机会（默认 3 次，视频 2 次），每节课另有若干备用框体。
- Vibe Coding 按每节课的对话轮数限制（后台可配，默认 10–12 轮）。
- 每次生成写一条记录：学生、课节、模型、token / 成本、耗时；机构端汇总查看。

### 3.5 模型适配层
- 图像：OpenAI GPT Image 2.5（文生图 `gpt-image-2.5-flare`，图生图 `gpt-image-2.5-sunburst`）；另有 mock。
- 文字：Claude Haiku 5.5（支持图片输入）。
- 视频：**暂缓**，mock 占位。
- 代码：Claude Agent SDK，用 Console API key 鉴权（Max 每月送的 API 额度可用；产品形态不能用 Max 登录态）。

## 4. 示例课程
课程数据按 S1–S3、每级 16 节设计，本期填 3 节：
1. 文生图 / 图生图 / 看图写作：召唤机甲英雄（机甲 → 萌宠 → 合体 → 角色档案 + 自由创作）
2. 图生视频：变身动画（视频暂用 mock）
3. Vibe Coding：用前两节的素材（图片 + 角色档案）做角色图鉴网页

## 5. 技术方案（已实现）
Next.js 15（App Router）+ SQLite（Drizzle + libSQL，Prisma 引擎在开发环境下载不了，改用纯 npm 方案）；画布用 React Flow；Vibe Coding 后端用 Claude Agent SDK，经 SSE 推流；写 HTML 时把流式内容直接推进预览（比文件监听更早可见）；按三种角色区分鉴权。代码在 GitHub `rundong013-oss/ai-edu`。

## 6. 不做
招生物料、获客、计费支付、多机构、真实视频生成、PPT/教案内容。

## 7. 待定
- 视频模型选型。
- 额度要不要在课堂里硬拦：灵动只在后台管人次，不在课堂里拦学生（见对标调研）。
- 学生做的网页能否调用大模型（S3 智能体、RAG 类课程需要）。
